User Stories — App d’échange de services par points

Un visiteur comprend directement l'offre de l'application

Un visiteur peut voir les pages publics

Un visiteur peut consulter les annonces

Un visiteur peut voir le détail d’une annonce

Un visiteur ne peux pas voir les coordonnées de l'annonce (mails / réseau / etc)

Un visiteur ne peux pas voir les profils utilisateurs et leur information personnelles

Un visiteur peut s’inscrire

Un utilisateur peut se connecter et se déconnecter

Un utilisateur peut créer une annonce

Un utilisateur peut modifier ou supprimer son annonce

Un utilisateur peut envoyer une demande de service

Un utilisateur peut suivre ses demandes envoyées

Un utilisateur peut recevoir une notification

Un utilisateur peut effectuer une transaction avec ses points

Un utilisateur a accès à son propre historique d'échange

Un utilisateur peut voir sa page "Mon profil"

Un administrateur peut gérer les annonces

Un administrateur peut gérer les utilisateurs

Un administrateur peut auditer les transactions de points

Un super-administrateur a les mêmes permissions qu'un administrateur

Un super-administrateur peut créer des administrateurs

Un utilisateur peut voir ses succes en cours / réalisé

Un administrateur peut ajouter / modifier / supprimer des succes

Un super administateur peut créer des articles de blog pour le journal de bord

Un utilisateur peut commenter une annonce

Un utilisateur peut mettre une annonce en favoris

Un utilisateur peut créer une chaine d'entraide

Un super administrateur peut créer des annonces monde pour les associations du monde
